# Personal Profile

Static personal profile site designed for GitHub Pages.

## Customize

1. Replace `Your Name`, `you@example.com`, `your-username`, `Your City`, project text, and technology tags in `index.html`.
2. Add your resume as `resume.pdf` in this folder, or remove the Resume link from the header.
3. Update the `YN` logo initials in the header.

## Publish with GitHub Pages

1. Create a GitHub repository named `your-username.github.io`.
2. Upload these files to the repository's `main` branch.
3. In GitHub, open **Settings > Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Your profile will be available at `https://your-username.github.io` after GitHub completes deployment.
